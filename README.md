# VkusOchka (Вкусочка) — Сервис доставки еды

Современное веб-приложение для заказа и доставки еды из ресторанов, разработанное с использованием ASP.NET Core для серверной части и React с Tailwind CSS для клиентской части.

## Архитектура и технологии

### Backend (Серверная часть)
* **Платформа:** .NET 10 / ASP.NET Core Web API
* **База данных:** Microsoft SQL Server
* **ORM:** Entity Framework Core (EF Core) с подходом Code-First
* **Аутентификация:** JSON Web Tokens (JWT) с шифрованием паролей через BCrypt.Net
* **Документация API:** Swagger / OpenAPI

### Frontend (Клиентская часть)
* **Библиотека:** React (Vite)
* **Стилизация:** Tailwind CSS
* **Маршрутизация:** React Router

---

## Функциональные возможности

1.  **Пользователи и авторизация:**
    * Регистрация и безопасный вход в систему.
    * Валидация вводимых данных (защита от пустых полей, некорректных символов, повторений).
    * Генерация и строгая проверка валидности JWT-токенов (Issuer, Audience, Срок действия).
2.  **Рестораны и меню:**
    * Просмотр списка доступных ресторанов и фильтрация по кухням.
    * Детальный просмотр меню ресторана с возможностью выбора блюд.
3.  **Корзина и оформление заказа:**
    * Добавление, изменение количества и удаление блюд из корзины.
    * Сохранение корзины в профиле (Избранные корзины).
    * Расчет стоимости, учет бонусного баланса пользователя при оформлении заказа.
4.  **Личный кабинет:**
    * Просмотр истории заказов.
    * Управление списком адресов доставки (с валидацией адреса).
    * Привязка банковских карт (с маскированием номера и проверкой формата).
    * Редактирование личных данных профиля.

## Структура проекта

```text
├── Controllers/            # Контроллеры веб-API
├── Models/                 # Модели данных и перечисления
├── Migrations/             # Миграции базы данных Entity Framework
├── frontend/               # Клиентское React-приложение

├── DbInitializer.cs        # Первоначальное заполнение БД
├── Program.cs              # Точка входа в backend-приложение
└── start.bat               # Скрипт автоматического запуска
```

## Запуск проекта

### Вариант 1. Быстрый запуск
В корневом каталоге репозитория запустите скрипт:
```cmd
start.bat
```
Он автоматически установит npm-пакеты, применит миграции и запустит обе части приложения.

### Вариант 2. Ручной запуск
**Backend:**
```bash
dotnet restore
dotnet run
```

**Frontend:**
```bash
cd frontend
npm install
npm run dev
```
